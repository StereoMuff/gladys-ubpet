# Changelog

All notable changes to this integration are documented in this file. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [semantic versioning](https://semver.org/).

Describe each change under `## [Unreleased]` as you make it. The Release
workflow moves that section under the version it ships, and the section becomes
the notes of the version's GitHub Release.

## [Unreleased]

### Added

- First version: UBPet / UPET litter boxes (C20, C10...) through the UPET cloud.
- Cleaning and levelling switches, a command list (clean, level, pause, resume,
  waste bin emptied, refresh), live status and cat presence.
- Waste bin level and use counter, deodorant days, visits in the last 24 hours,
  last visit, auto clean switch and delay.
- Scene triggers: cat visit (cat, weight, duration), waste bin full, box blocked.
- Movement refused while a cat is inside or near the box.
